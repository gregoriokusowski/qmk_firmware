# Kusowski Preonic

Hand-wired 5x12 ortholinear on an ATmega32U4 controller with a Pro Micro pin-out.

* Keyboard Maintainer: [Gregorio Kusowski](https://github.com/gregoriokusowski)
* Hardware Supported: Pro Micro pin-out ATmega32U4 with the Atmel DFU bootloader (for example an Elite-C)

Make example for this keyboard (after setting up your build environment):

    make handwired/kusowski_preonic:gregoriokusowski

Bootloader: press the reset button on the controller.
